Conectar con GitHub

Solo la primera vez en este navegador. La clave se guarda aquí, en tu navegador, y no se sube a ningún lado.

¿Cómo saco el token?
  1. Entra a github.com/settings/personal-access-tokens/new.
  2. Nombre: plancito-admin. Vencimiento: el que prefieras (por ejemplo 1 año).
  3. En Repository access elige Only select repositories → plancito.
  4. En Permissions → Repository permissions → Contents elige Read and write.
  5. Haz clic en Generate token, cópialo y pégalo aquí.
